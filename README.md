Project Overview
This project focuses on the SQL analytics of the Olist E-Commerce dataset (a major Brazilian marketplace) containing over 99k+ transactions. Then, I wrote 5 specific SQL queries to answer major business questions that an online company would want to know.

Skills I Used
1. Database Creation: Writing T-SQL code to build empty tables and define data types.
2. Relational SQL Queries: Using JOIN to connect separate tables together.
3. Data Aggregation: Using SUM and COUNT to calculate financial and volume totals.
4. Data Organization: Using GROUP BY and ORDER BY to sort and categorize the final results.

The 5 Business Questions I Answered
1. Which states give us the most customers?
This counts the total number of unique customers in every state to see where our biggest user base lives.

2. What is our total gross revenue?
This adds up the prices of every item ever sold to give the company one grand total of all the money made.

3. Which states generate the most revenue?
This connects the customer table to the sales table to show exactly which locations are spending the most money so marketing teams know where to focus.

4. What are the top 5 most common order statuses, and how much total freight (shipping cost) was spent on them?
This groups orders by their status (like delivered, shipped, or canceled) and calculates the exact shipping costs for each group to track operational spending.

5. Top 10 Highest-Spending Individual Customers
This searches the entire database to find our top 10 customers based on their total history of purchases for future loyalty rewards.

Dataset Link
The raw data used for this project is the **Olist Brazilian E-Commerce Dataset**, which can be downloaded directly from Kaggle.
